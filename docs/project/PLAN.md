# Pacific Star — PLAN

Рабочий трекер задач проекта переработки pacificstar.ru. Источник истины по объёму и критериям приёмки — `docs/project/PacificStar-Cursor-Plan.md` (**версия 1.2** от 08.09.2026; раздел 11 имеет приоритет при расхождениях). Здесь ведётся оперативный статус.

Идентификаторы `PS-XX` — стабильные идентификаторы плана, **не** номера GitHub issues.

Статусы: `BACKLOG → READY → IN_PROGRESS → IN_REVIEW → READY_FOR_CI → MERGED → VERIFIED`. `READY_FOR_CI` — локальная готовность, но НЕ успешный удалённый CI и НЕ публикация. `BLOCKED` — известная внешняя причина остановки. `VERIFIED` — только после проверки фактического результата (включая публикацию). `MERGED` не означает, что опубликованная версия работает.

> Примечание по трекингу: в текущей среде Cloud Agent нет доступа на запись к GitHub Issues (`gh` доступен только на чтение, отдельного инструмента создания issues нет). Пока это ограничение не снято, роль карточек задач выполняет этот файл. См. `DECISIONS.md` и `STATE.md`.

## Критерии приёмки (кратко)

Полные критерии — в `PacificStar-Cursor-Plan.md`, раздел 5. Ключевые опорные точки:

- **PS-01**: старые ИНН `2508139498` и ОГРН `1192536024498` отсутствуют в актуальном публикуемом контенте; корректные реквизиты совпадают во всех представлениях; банковские строки и два ЭДО ID сохранены точно; продажи и курьерская доставка разделены.
- **PS-03**: тесты корректного запроса, ошибки сервера/сети, неверных полей и дубля; реальные клиентские данные не отправлять; end-to-end доставку не объявлять проверенной без тестового канала. Важно: production-доставка идёт через **PHP `api/*.php`** (см. `js/config.js`), а не через Node `server.js`; dev-проверка Node-фоллбэка доставку не подтверждает.
- **PS-05**: посетитель не видит непроверенную стоимость; заявка сохраняет введённые данные; числовой калькулятор возвращается только в PS-13 после тарифных данных.
- **PS-06**: первый экран и базовые контакты/навигация доступны без ожидания всех ресурсов и без JS; замеры до/после с указанием среды.
- **Дизайн-задачи (PS-07…PS-10)**: без реального макета/экспорта Canva и спецификации остаются `BLOCKED_BY_DESIGN` (раздел 3А плана).
