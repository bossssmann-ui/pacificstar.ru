# PS-08 — Карта существующих страниц

Инвентаризация действующих страниц для реструктуризации главной и навигации (PS-08). Готовится без редизайна; визуальная реализация — после макетов Canva (`DESIGN_READY`). Язык интерфейса переключается клиентски (см. `I18N-INVENTORY.md`); отдельных языковых URL-страниц нет.

Основной CTA по всему сайту — **«Запросить расчёт» → `contacts.html#contactForm`** (реально существующая форма). Обратный звонок — `callback-panel` (компонент).

## Ключевые пересечения (для PS-08, развести без удаления URL вслепую)
1. **Авто:** `avto-dfo.html` ↔ `truck-delivery.html` — обе про автодоставку; определить разные интенты (районы ДФО vs магистральные автоперевозки) или объединить с редиректом (не терять URL/ссылки/sitemap).
2. **Море/удалённые:** `remote-regions.html` ↔ `severnyy-zavoz.html` ↔ `kabotazh.html` — морское плечо перекрывается; развести по интенту (закон 411-ФЗ/сезон vs межпортовый каботаж vs общий морской хаб).
3. **Хаб vs листинги услуг:** `services.html` дублирует часть содержания сервисных страниц — оставить как навигационный хаб, не как дубль.

## Предполагаемые переходы (воронка)
- `index` → сервисная страница (по задаче) → `cases` (доказательство) → `contacts#contactForm` (заявка).
- `index` → `services` (хаб) → конкретная услуга → `contacts#contactForm`.
- `news` / `about` → сервисная страница → `contacts#contactForm`.
- Сквозной CTA «Запросить расчёт» на всех публичных страницах ведёт в единую форму.

## Действия PS-08 (после DESIGN_READY)
- Реструктурировать главную: направления по задачам → доказательства/кейсы → транспорт → география → документы → обращение.
- Развести пересекающиеся авто-/морские страницы; сохранить URL и внутренние ссылки, при снятии — редирект, не на главную.
- Убрать фиктивную ссылку VK `#`; единые иконки; cookie/плавающий контакт не перекрывают форму.
- `logos.html` — подтвердить служебный статус (noindex/исключение из публикации).
