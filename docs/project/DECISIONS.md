# Pacific Star — DECISIONS

Принятые решения и их основания. Дополнять по мере работы.

## PS-00 (7 сентября 2026)

1. **Трекинг задач в репозитории, а не в GitHub Issues.** Основание: в среде Cloud Agent нет доступа на запись к Issues (`gh` только на чтение). Задачи PS-XX ведутся в `docs/project/PLAN.md` со стабильными идентификаторами. При появлении доступа — синхронизировать с Issues без дублей.
2. **Агент не выполняет merge.** Основание: merge в `main` автоматически публикует сайт (релиз), а политика среды запрещает автоматический merge без явного указания. PR оставляется владельцу на ревью и merge. Это не отменяет остальной цикл работы.
3. **Внутренняя документация исключена из публикации.** Основание: деплойный `rsync` не исключал `docs/` и `.cursor/`, из-за чего внутренние файлы попали бы на сайт. Добавлены `--exclude='docs/'` и `--exclude='.cursor/'` в `tilda-deploy.yml`. Это обоснованное изменение деплоя, не PR-гейта, и не ослабляет проверки.
4. **«Три проверки» не подтверждены — не выдумываем названия.** Основание: на реальных PR присутствует только `GitGuardian Security Checks`; защита ветки недоступна токену (403), rulesets пусты. Зафиксировано в `CI-CONTRACT.md` как блокировка; запрошены точные названия и/или доступ.
5. **Правило Cursor добавлено, существующие инструкции не перезаписаны.** Основание: раздел 2 плана. `.cursor/rules/pacificstar-workflow.mdc` ссылается на `docs/project/*` и `.github/copilot-instructions.md`, не дублируя их.
6. **Стек не переписываем.** Основание: раздел 3 плана и `.github/copilot-instructions.md` — vanilla HTML/CSS/ES5-JS без фреймворков и сборки.
