# PS-07A — Спецификация бренда и перечень экранов Canva

Статус: **доступные части подготовлены локально (READY_FOR_CI)**. Это спецификация для реализации через Canva, **не** самостоятельный редизайн. Реализация PS-07/08–10 — только после `DESIGN_READY` (утверждённые макеты Canva) и получения исходников логотипа.

Источник данных: сводка владельца по `Pacific_Star_Brand_System.md` и решению `30_Decisions/2026-05-12-PS_brand_direction.md`. Исходные документы System-A напрямую не читались — значения ниже перенесены из плана v1.2 (раздел 11.3). Названия цветов раздела 4 брендбука синхронизируются с новой палитрой в спецификации; исходный vault не редактируется без доступа.

---

## 1. Утверждённое направление

**Направление D «Печать Меридиана»** — утверждено (решение 12.05.2026). Старые сине-золотые варианты и раннее предпочтение бело-голубой палитры **не** задают новую визуальную систему и не должны использоваться как основа.

> Важно: текущая реализация сайта пока построена на старой сине-золотой палитре (см. §3 «как есть»). Переход на направление D — это отдельная реализация после утверждения макетов Canva, а не правка в этой задаче.

## 3. Текущие токены сайта («как есть», для порядка замены)

Из `css/style.css` (`:root`) — **старая** сине-золотая система, подлежащая замене при реализации направления D:

| Текущая переменная | Текущее значение | Целевой токен D |
|---|---|---|
| `--color-primary` | `#0d2b5e` | Stamp Ink `#1F2A35` |
| `--color-secondary` | `#1a4da0` | (пересмотреть; вторичный по D) |
| `--color-accent` | `#f5a623` | Customs Orange `#B8531C` |
| `--color-accent-dark` | `#d4891a` | (производный от Customs Orange) |
| `--color-text` | `#2c3e50` | Stamp Ink / Steel `#5C6470` |
| `--color-light` | `#f4f7fc` | Document `#F2EDE3` |
| `--color-muted` | `#6c757d` | Steel `#5C6470` / Mist `#9CA8B5` |
| `--font-sans` | `Inter, …` | Заголовки Inter Display; текст Golos Text; метки JetBrains Mono |
| `--radius` / `--radius-lg` | `6px` / `8px` | 4 / 8 / 16 px |

**Порядок замены (для будущей реализации, не сейчас):** (1) объявить токены D в `:root` рядом со старыми; (2) заменить цветовые переменные по таблице; (3) подключить шрифты (self-host, как Inter в PS-06); (4) выровнять радиусы/сетку; (5) заменить икон-набор; (6) визуальная сверка с экспортами Canva на всех экранах §5.

## 4. Логотип (исходники требуются — не восстанавливать по догадке)

Два регистра (по сводке владельца):
- `Logo_Pacific_Star_Seal_Full.svg` — полная печать, минимум 56 px.
- `Logo_Pacific_Star_Mark.svg` — малый знак, минимум 16 px.

Эти исходники **здесь не получены и не просматривались**. Утверждённую геометрию логотипа восстанавливать по догадке нельзя. В репозитории есть старые `img/logo*.svg` (сине-золотые) — это НЕ утверждённый знак направления D и не заменяют исходники.

**Блокер:** до финализации Canva нужны 2 SVG (Seal Full + Mark) и **раздел 3 брендбука**.

## 5. Перечень экранов для Canva (направление D)

Подготовить макеты (desktop и mobile, с состояниями), сохранить для каждого реальный design URL/ID, дату/версию, экспорт, размеры, шрифты, цвета, интервалы, состояния компонентов и правила адаптации:

1. **Главная — desktop**
2. **Главная — mobile**
3. **Первый экран (hero)** — спокойная зона под текстом, короткий предметный заголовок о логистике ДВ, одна основная кнопка «Запросить расчёт».
4. **Меню/навигация** (desktop + mobile): Услуги, Техника, Проекты, Контакты в доступной навигации; новости/вакансии второстепенны; убрать фиктивную ссылку VK `#`.
5. **Шаблон страницы услуги**
6. **Шаблон кейса** (карточка проекта)
7. **Шаблон новости** (лист статьи; согласовать с PS-16B: карточки листинга, «Показать ещё», блок «Источник»).
8. **Формы — 3 состояния:** (a) ошибка валидации, (b) отправка/загрузка, (c) успех. Cookie-баннер и плавающий контакт не перекрывают форму.

## 6. Критерии сверки Canva → код (для приёмки PS-07/08–10)

- В дизайн-PR приложить ссылку/версию Canva, исходный экспорт и скриншоты реализации в тех же размерах; описать допустимые отличия из-за адаптивности.
- Реализация — семантический HTML, доступные формы, адаптивная сетка, текст доступен поисковикам (экспорт не вставлять одной картинкой).
- Изображения/логотипы — только с разрешёнными правами; не выдавать иллюстрацию за фото собственного парка.
- Три проверки GitHub обязательны, но не заменяют визуальную сверку и редакционную приёмку.

## 7. Блокеры и зависимости

- **DESIGN_READY** (утверждённые макеты Canva по направлению D) — обязателен до PS-07/08–10. Технические PS-03…PS-06 от него не зависят.
- Исходники логотипа (2 SVG) + раздел 3 брендбука — требуются (действие владельца).
- Условие «после регистрации ТЗ» — уточнение условия публичного выпуска бренда; не блокирует подготовку макетов.
- Повторное разрешение на выбор уже утверждённого направления D не требуется.
