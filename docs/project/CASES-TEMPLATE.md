# PS-10 — Шаблон сбора фактуры для реальных кейсов

Шаблон для сбора данных под **минимум 6 реальных кейсов** (цель PS-10). Пустой шаблон **не считается** наполнением страницы; каждый опубликованный кейс должен иметь источник фактов и права на материалы. Числа кейсов не выдумывать; при отсутствии данных — оставлять поле пустым и помечать `BLOCKED` (нужны материалы владельца).

Заполняется владельцем/Романом. После заполнения — редакционное ревью до публикации. Персональные данные в документах-подтверждениях убирать.

## Поля кейса (обязательные)

| Поле | Описание | Обязательно | Примечание |
|---|---|---|---|
| `id` | Короткий идентификатор (напр. `case-2025-chukotka-01`) | да | стабильный, для URL/якоря |
| Заголовок | Короткий предметный (что/куда) | да | без выдуманных суперлативов |
| Дата / период | Месяц-год или период проекта | да | реальный |
| Направление | Северный завоз / каботаж / негабарит / авто / ж/д / ВЭД | да | связать с сервисной страницей |
| Маршрут | Пункт А → Пункт Б (плечи) | да | реальная география |
| Груз | Тип, масса/объём, особенности | да | напр. «продовольствие, 120 т» |
| Задача | Что требовалось решить | да | контекст клиента |
| Решение | Как выполнили (техника, схема, этапы) | да | конкретика без вымысла |
| Результат | Итог (сроки/сохранность/эффект) — **как факт свершившегося**, не как обещание | да | не превращать в текущий SLA |
| Источник фактов | Откуда данные (внутренний акт/клиент/документ) | да | для проверки Романом |
| Подтверждение/фото | Фото/скан (с правами на публикацию, без ПДн) | да для публикации | иначе `BLOCKED_MEDIA` |
| Права на материалы | Кто владелец фото/логотипов; разрешение | да | логотип оператора ≠ его рекомендация |
| Отзыв клиента | Только подтверждённый, с согласия | нет | не выдумывать |
| Статус | `DRAFT` / `READY_FOR_REVIEW` / `BLOCKED_*` | да | воронка готовности |

## Правила
- Исторический результат кейса **не подтверждён** только потому, что он исторический — нужен источник факта (эта проверка — область PS-10, а не PS-02).
- Результат формулировать как свершившийся факт конкретного проекта, а не как гарантию будущим клиентам (не создавать новый SLA).
- Не выдавать сгенерированную иллюстрацию за фото собственного парка; фото — только с правами.
- Логотип портового оператора не выдавать за его рекомендацию компании.
- Нехватку качественных кейсов фиксировать как `BLOCKED`, а не заполнять шаблон вымышленными данными.
